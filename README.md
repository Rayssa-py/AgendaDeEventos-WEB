## 📌 Sobre o Projeto

Este projeto consiste em uma página web desenvolvida para divulgar a programação dos três principais eventos comunitários e religiosos das igrejas AD MONTESE e AD COMADESMA, unindo uma estrutura HTML semântica a um design estilizado com CSS.

### 🗓️ Eventos em Destaque

1. **2º EBOM — SETOR 24**
   * **Tema:** *O Raso Não Me Satisfaz Mais* (baseado em Ezequiel 47).
   * **Data:** 29 e 30 de Agosto de 2026.
   * **Local:** CE 065, 31 - Sapupara / Maranguape.
   * **Atrações:** Dupla Maranata, Dupla Kargela e Daniel, Pr. Presidente Osires Junior.

2. **Congresso Unificado de Senhoras e Jovens**
   * **Data:** 8 e 9 de Agosto de 2026.
   * **Local:** Rua Flor Primavera, 169 — Bairro Lameirão, Maranguape - CE.

3. **Festa de Senhoras**
   * **Tema:** *Arrebatamento* (1ª Tessalonicenses 4:16,17).
   * **Data:** 12 de Setembro de 2026.
   * **Local:** Rua Ana Florença, Penedo — Maranguape - CE.

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica do conteúdo da página.
* **CSS3**: Estilização visual, cores, tipografia e organização de layout.

## 🚀 Como Executar o Projeto Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/Rayssa-py/AgendaDeEventos-WEB.git
   ```

2. Navegue até a pasta do projeto:
   ```bash
   cd AgendaDeEventos-WEB
   ```

3. Abra o arquivo `index.html` em qualquer navegador de sua preferência.
